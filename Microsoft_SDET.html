Project Overview

SDET role on an enterprise React SPA. Built and maintained end-to-end automation focused on reliability, coverage, and maintainability. Implemented test architecture for production-like validation with CI integration and clear triage practices.

Tech Stack

Playwright 1.54 TypeScript 5.4 React 18 SPA Fluent UI v9 MSAL 3 Azure AD Azure DevOps Pipelines Highcharts Validation AI-Assisted Development

Used TypeScript + Playwright for browser automation, executed authenticated test flows with real user sessions, and integrated results into Azure DevOps pipelines for consistent delivery quality.

Testing Strategy and Validation

Shared Context and Lifecycle Management

Implemented shared browser contexts and recovery guards to reduce execution overhead and improve suite resilience.

Page Health Gating

Added health checks before execution to skip safely when prerequisites fail, reducing false failures and improving reliability signal.

Feature-Flag Aware Validation

Designed tests to branch based on live feature state instead of hardcoded assumptions, enabling reliable multi-environment test runs.

Data-Driven Assertions

Validated filters and metrics by capturing before/after values and asserting numeric relationships. Implemented parsing for formatted values to support deterministic comparisons.

Chart and Integration Verification

Verified chart behavior through DOM assertions and tested critical cross-workflow navigation paths with real authentication and backend data.

Quality Operations and Ownership

Test Authoring and Utilities

Mapped tests to work items, built reusable helper utilities, and centralized locator strategy for easier maintenance.

Accessibility-First Locator Strategy

Used ARIA role/label-based locators to align with accessibility standards and reduce brittle selector failures.

AI-Accelerated Workflow

Used AI tools for test scaffolding and helper generation while maintaining code review discipline and deterministic assertions.

Impact

  • Higher signal quality: Health gating and resilient setup reduced false negatives.
  • Scalable maintenance: Shared utilities and centralized locators simplified updates.
  • Cross-environment confidence: Feature-aware, auth-backed tests improved release trust.
  • Faster delivery loops: CI integration and AI-assisted workflows increased throughput.

Amazon Bot

Automated Purchase Assistant

Project Background

Developed during 2021 GPU shortage to automate availability monitoring and purchasing. Built with Python and Selenium for practical problem-solving experience.

Technical Implementation

Python Selenium WebDriver Web Automation Browser Control DOM Manipulation

Implementation Approach

Automated workflow: launch browser, navigate to product page, monitor for availability, execute purchase with saved credentials, and complete checkout.

Key Features

  • Real-time product availability monitoring with configurable refresh intervals
  • Automated form filling, credential management, and checkout completion
  • Error handling for common web elements and browser session management

Technical Challenges

Encountered bot detection and CAPTCHA verification, platform-specific design requiring custom selectors, rate limiting with refresh rates, and dynamic content updates.

Learning Outcomes

Gained experience with Selenium WebDriver, Python automation, web scraping, browser automation challenges, anti-bot countermeasures, and error handling in automated systems.

Future Improvements

Potential enhancements include:

  • CAPTCHA solving integration or human verification prompts
  • Multiple website support with configurable selectors
  • Proxy rotation to avoid IP blocking
  • More sophisticated timing and randomization to appear more human-like
  • Notification systems (email/SMS) when products become available
  • Price monitoring and threshold-based purchasing

Eversource - React Client Dashboard

React Dashboard Development with Power BI, Azure Hosting, and Enterprise Access Controls

Built a React dashboard from design to production, collaborating with designers and stakeholders on UX. Delivered two client websites for the same organization at masssavedata.com and ctenergydashboard.com.

Technical Architecture

React JSX CSS3 REST APIs Power BI Embedded Azure App Service Azure CLI Azure Monitor / Application Insights Azure AD Azure Key Vault Redis JavaScript ES6+

Repository Foundation

Component Development

Built scalable React components with reusable patterns for complex data displays.

Multi-Client Modular Architecture

Maintained a single modular repository for both client sites, reusing shared sections and components while supporting client-specific configuration.

Integration Challenges

Power BI Embedded

Integrated Power BI reports despite authentication complexity and browser compatibility challenges.

REST API Integration

Integrated multiple API endpoints with error handling and clean data flow management.

Team Collaboration
